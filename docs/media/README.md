# Медиа для README

Скриншоты и гифки мобильного приложения, которые встраиваются в корневой
[README.md](../../README.md).

## Как снимать

Съёмка идёт на iOS-симуляторе: рамка телефона выглядит уместнее в README, чем окно
macOS-приложения, а `simctl` умеет снимать и экран, и видео без сторонних утилит.

```bash
# 1. Симулятор
xcrun simctl boot "iPhone 17 Pro"
open -a Simulator

# 2. Приложение против тестового контура
cd tourism-mobile
flutter run -d "iPhone 17 Pro" \
  --dart-define=APP_ENV=test \
  --dart-define=DATA_SOURCE=api \
  --dart-define=API_BASE_URL=https://86-106-20-132.sslip.io

# 3. Вход: любой номер, код 1234 (тестовый контур принимает любой)

# 4. Снимок экрана
xcrun simctl io booted screenshot docs/media/<имя>.png

# 5. Видео (Ctrl+C останавливает запись)
xcrun simctl io booted recordVideo --codec h264 /tmp/clip.mov
```

## Из видео в гифку

```bash
ffmpeg -i /tmp/clip.mov -vf "fps=12,scale=380:-1:flags=lanczos,split[a][b];\
[a]palettegen[p];[b][p]paletteuse" -loop 0 docs/media/<имя>.gif
```

`fps=12` и ширина 380 — компромисс: гифка остаётся читаемой и весит порядка мегабайта.
GitHub не любит тяжёлые гифки в README, выше 3 МБ лучше не подниматься.

## Что и где встроено

В README стоят HTML-комментарии-якоря, по ним видно, куда что идёт:

| Якорь | Что показать |
| --- | --- |
| `MEDIA:HERO` | Главный экран — первое впечатление |
| `MEDIA:CATALOG` | Каталог мест и карточка места |
| `MEDIA:MATCH` | Подбор по параметрам и/или диалог с Тревел Агентом |
| `MEDIA:EXECUTION` | Прохождение маршрута с картой |
| `MEDIA:PROFILE` | Профиль: звания, достижения, статистика |

## Правила

- **Только настоящее приложение.** Figma-макеты из
  `tourism-platform/docs/design/` в README не идут: они показывают замысел,
  а не то, что реально работает. Выдавать одно за другое — врать читателю.
- **Без персональных данных.** Тестовый аккаунт, тестовые номера. Перед коммитом
  проверить, что на кадре нет чужих имён, телефонов и реальных фото профилей.
- **Тёмная или светлая тема — одна на все кадры**, иначе подборка выглядит рвано.
