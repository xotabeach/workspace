# Скриншоты для README

Корневой [README](../../README.md) показывает реальные экраны мобильного
приложения. Текущая подборка получена 26 сентября 2026 года из переданных
командой снимков: заставка, главная, каталог, подбор и ИИ-чат, карточка и карта
маршрута, старт/прохождение/пауза/история, профиль и уведомления.

Файлы с суффиксом `-current.jpg` названы по показанному сценарию; `alt` в
корневом README описывает содержимое каждого кадра. Перед следующей
публикацией нужно проверить, что снимки показывают работающий интерфейс и не
содержат телефоны, адреса, токены или чужие персональные данные. Версию
опубликованного APK нельзя выводить из даты этих снимков.
